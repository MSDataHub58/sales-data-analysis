# 📊 Deaths in Armed Conflicts — Data Analysis

An exploratory data analysis and Power BI dashboard project analyzing deaths associated with armed conflicts from **1989 to 2024**.

## 📌 Project Overview

This project analyzes historical conflict-related death data to identify major trends, peak years, countries with the highest recorded deaths, and regional patterns.

The project includes both **Excel-based analysis** and an interactive **Power BI dashboard**.

## 🎯 Objectives

- Analyze deaths associated with armed conflicts over time.
- Identify countries with the highest recorded deaths.
- Find major peak years in the dataset.
- Compare conflict-related deaths across regions.
- Transform raw data into meaningful visual insights.
- Build an interactive Power BI dashboard.

## 🛠️ Tools Used

- **Microsoft Excel**
- **Power Query**
- **Microsoft Power BI**
- **Data Cleaning**
- **Exploratory Data Analysis (EDA)**
- **Data Visualization**

## 🔍 Key Insights

- **1994** appears as a major peak year in the dataset.
- Rwanda, Syria, Ethiopia, Ukraine, and Afghanistan are among the countries with the highest recorded deaths.
- Conflict-related deaths vary significantly across different years.
- Regional patterns show substantial differences in the distribution of deaths.
